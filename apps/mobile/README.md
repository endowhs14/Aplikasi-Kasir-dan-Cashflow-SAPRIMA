# SAPRIMA Kasir — Flutter

Lihat [README utama](../../README.md) untuk toolchain, build, instalasi, scope dan batas keamanan. Kode domain di `lib/domain`, penyimpanan SQLCipher di `lib/data`, dan antarmuka di `lib/ui`.

`flutter test` menjalankan fixture uang, database terenkripsi dan widget UI. `python3 tool/check_crash.py` menjalankan proses terpisah untuk membuktikan recovery transaksi sebelum/sesudah komit.
